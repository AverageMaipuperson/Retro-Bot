# Retro Bot
Retro Bot <span style="font-size: 0.8em; color: gray;">(also known as rbot)</span> is a macro bot for Geometry Dash built for the versions **1.0-1.7**

> [!IMPORTANT]
> Retro Bot at this state is in it's early stages so I'd really appreciate if you joined our [Discord Server](https://discord.gg/bMpBqMMF2w) and gave feedback or reported bugs for us!

## Known Issues:
- Mirror portals break macros
- Not using physics bypass also breaks macros
- Really messy codebase
